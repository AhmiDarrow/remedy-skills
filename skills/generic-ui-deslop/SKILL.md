# Generic Ui Deslop

## When to use
Every screen has the same centred hero, gradient, three feature cards and rounded boxes, or UI is about to be built with no visual direction.

## Steps
1. Write three facts before styling: who uses it and in what setting, the main thing they do, and two or three adjectives with their opposites (precise, not playful). Reuse existing brand assets and tokens if present.
2. Screenshot the current screens and mark each default: stock gradient, uniform card grid, identical radius and shadow everywhere, emoji as icons, centred body text, vague headline, decorative blobs, every section the same height.
3. Choose one distinctive idea drawn from the subject itself, such as its data, artefacts, vocabulary or materials. Let it drive layout, not just color.
4. Set a type pairing or single family with real contrast in size and weight, using fonts the project is licensed for.
5. Build a restrained palette: tinted neutrals, one accent reserved for action and meaning.
6. Vary composition by content importance: asymmetry, alignment to a clear edge, dense where users compare, generous where they decide. Remove boxes that spacing can replace.
7. Use real content, real screenshots and honest numbers; mark anything still missing instead of inventing testimonials or statistics.
8. Apply to one representative screen, show before and after, then extend after agreement.
9. Check contrast, focus visibility and narrow widths.

## Watch out for
- Swapping one fashionable style for another is still generic; each choice should have a reason tied to step 1.
- Novel navigation or controls that cost users comprehension are not identity.
- Copying a particular competitor's look creates confusion and possible legal trouble.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Each marked default is replaced or justified, the choices trace to the written facts, the sample screen passes contrast and narrow-width checks, and the user has seen the comparison.
