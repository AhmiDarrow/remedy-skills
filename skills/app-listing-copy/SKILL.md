# App Listing Copy

## When to use
A mobile app, desktop app or extension needs its title, descriptions and release text.

## Steps
1. Fetch each target store's current listing guidelines; note every field, its character limit and which fields are searchable. These differ by store.
2. Verify features by reading the product or its release notes, per platform.
3. Draft the name and subtitle or short description around what the app does, in words users would search.
4. Make the first lines of the long description answer what it does and for whom, since the rest is collapsed.
5. List main features as user outcomes. State requirements, paid features and subscription terms plainly.
6. Plan screenshots in order, each showing one real screen with a short caption.
7. Check that privacy statements and data declarations match what the app and its libraries collect.
8. Count characters per field per locale and leave submission to the user.

## Watch out for
- Competitor names or trademarks in keyword fields.
- "Best" or "number one" claims, and prices inside screenshots, that stores may reject.
- Mock-ups showing features that do not exist.
- Translated text overflowing limits that the source fit.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Every field is within its verified limit and each claimed feature exists on that platform.
