# Mistake Pattern Diagnosis

## When to use
There are several completed, marked or practice items with errors.

## Steps
1. Use returned or practice work, with the learner's own steps. Final answers alone hide the cause.
2. For each error, find the first wrong step and quote it.
3. Verify the correct solution yourself, and consider that the marking may be wrong.
4. Classify: misconception, missing prerequisite, procedure slip, misread question, recall gap, time pressure, notation or units.
5. Ask the learner to talk through one or two wrong steps. Their reasoning often reveals a consistent but false rule.
6. Group errors by cause, not by chapter.
7. Test the suspected misconception with a new item designed so that the false rule and the correct rule give different answers.
8. Choose the one or two causes with the most impact and give a targeted fix: contrast cases for confusions, drill for slips, reading routine for misreads.
9. Recheck those causes with fresh items several days later.

## Watch out for
- "Careless mistake" is a label that often hides a repeatable rule.
- One error is not a pattern; gather more before diagnosing.
- Redoing the same questions right after seeing solutions measures memory of the solution.
- Describe errors as fixable behaviour, not ability.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Each main cause has evidence from the work and a probe item, and a dated recheck is planned.
