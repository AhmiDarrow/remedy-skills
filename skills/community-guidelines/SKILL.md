# Community Guidelines

## Steps
1. Values and scope (where rules apply).
2. Allowed vs prohibited behaviors.
3. Reporting path.
4. Enforcement ladder (warn → restrict → ban).
5. Appeals.
6. Keep enforceable and clear.

## Operating rules
- Prefer read-only exploration before changing files.
- Report commands and outcomes; do not invent results.
- Ask before destructive, paid, or irreversible actions.
- Never print or commit secrets, tokens, or private personal data.
- Use Remedy's tool names (`read`, `write`, `bash`); do not assume a tool that is not in your tool list.

## Done when
The user goal is met, or you list concrete blockers and the next safe step.
