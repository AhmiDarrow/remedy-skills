# Passport Visa Check

## When to use
Travel crosses a border and a document problem could stop boarding.

## Steps
1. For each traveller note nationality or nationalities, residence status, passport expiry and issue date, blank pages, and any name mismatch with the booking. Do not ask for full passport numbers.
2. Map every stop, including transits and airport changes, and the purpose: holiday, work, study, family visit. Purpose changes what is permitted.
3. Check official sources: the destination's immigration authority or embassy, plus the traveller's foreign ministry advice. Save URL and date checked.
4. For each border record validity rule, visa or electronic authorisation, processing time, fee, onward ticket or funds proof, health entry documents and permitted length of stay.
5. For repeat visits, calculate days used under any rolling-window limit from actual entry and exit dates.
6. For children travelling without both parents, check consent letter and birth certificate expectations.
7. Work backwards from departure with processing time and a margin; add reminders.
8. Mark ambiguous cases to be confirmed with the consulate.

## Watch out for
- Many places require months of validity beyond arrival or departure, and the number varies.
- Look-alike visa agent sites charging extra; navigate from the government's page.
- A transit can need its own visa, especially when collecting bags.
- Rules change, so recheck shortly before leaving.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.

## Done when
Every traveller and border has a dated official source and a status, and applications have deadlines.
