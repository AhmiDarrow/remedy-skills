# Script To Storyboard

## When to use
A script exists and someone must now decide what the camera or frame shows, line by line.

## Steps
1. Read the whole script first. Ask for the aspect ratio, target length, how it will be made (live action, screen capture, animation) and what is fixed: locations, cast, props, budget, shoot time.
2. Split it into beats where the viewer needs new information or the emotion turns. A beat gets one or more shots; a sentence is not automatically a shot.
3. Make one row per shot: ID (scene.shot), script line or action, size (wide, medium, close, insert), angle, camera or element movement, frame description, dialogue or sound, on-screen text, estimated seconds.
4. Describe each frame so it can be drawn: who is where in the frame, facing which way, foreground and background, and where the eye should land.
5. Give every shot a reason. Where the picture only repeats the words, propose showing a consequence, detail or reaction instead.
6. Check continuity across cuts: screen direction, eyelines, the 180-degree line, hand and prop positions, wardrobe, time of day. Mark any intentional break.
7. Time dialogue by reading it at speaking pace, add time for silent action, sum the rows and compare with the target. Propose specific cuts if over.
8. Flag costly or risky shots (crowds, vehicles, effects, extra locations) with a cheaper alternative.
9. If they will shoot it, add a second list ordered by location and setup, keeping the same shot IDs.

## Watch out for
- A run of same-size shots from the same angle cuts together as jumps.
- On vertical frames, wide two-person compositions and lower-third text often do not survive.
- Rewriting dialogue silently while boarding. List suggested script changes separately.
- Text descriptions are not drawn frames; say so if the user expects images.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Every line of the script maps to at least one numbered shot with framing, sound and duration, the total is compared with the target, and continuity and feasibility problems are listed.
