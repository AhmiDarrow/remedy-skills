# Quote Verification

## When to use
The user wants to use a quotation, or asks "did this person really say that?"

## Steps
1. Search a short distinctive run of 5 to 8 words in quotes, then a second run from elsewhere in the quote, since paraphrases vary in different places.
2. Look for the earliest dated appearance. Treat quote collection sites and image macros as leads only.
3. Get to the primary form: a speech transcript, recording, book page, filed document or the speaker's own post.
4. Compare word for word. Mark cuts, bracketed insertions and tense changes.
5. Read at least the paragraphs before and after. Check whether the speaker was quoting someone else, being ironic, stating a view in order to reject it, or speaking conditionally.
6. For translated quotes, find the original-language text and name the translator or edition.
7. Give one verdict: verified verbatim; real but altered (show both); real but misattributed (name the actual origin if found); or no source found.

## Watch out for
- Famous names attract orphan quotes. An attribution that first appears decades after the person's death, with no document, is a strong warning.
- "No source found" is not proof it was never said. Report what you searched.
- Published interview transcripts can be condensed. If a recording exists, it outranks the transcript.
- Never repair a quote so it reads better. Paraphrase outside quotation marks instead.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
The quote has a verdict plus a locatable citation (page, timestamp or paragraph), or is flagged as unverified so it is not presented as a quotation.
