# Job Application Tailor

## When to use
There is a specific posting and an existing CV or work history.

## Steps
1. Read the whole posting. Split requirements into essential, preferred and filler; note application instructions such as file type, length limit and questions.
2. Build an evidence table: each requirement, the matching experience from the user's material, and strength (direct, transferable, none).
3. Ask about weak rows. People often leave out relevant work. If there is none, record a gap; do not fill it.
4. Reorder so the strongest matching evidence appears in the top third of page one. Cut or shrink what does not serve this role.
5. Rewrite bullets as action, scope and result. Use only figures the user gave; if a number would help, ask, and accept "unknown".
6. Use the posting's terms where they truthfully describe the same thing. A tool they merely watched others use is not a skill they have.
7. Write a short cover note: the role, two pieces of evidence tied to its main needs, a real reason for interest, and a plain close. Avoid restating the CV.
8. Save as a new version and show a change list so they can confirm every claim. Check names, dates, titles and contact details against the original.
9. Report remaining gaps honestly. The user submits.

## Watch out for
- Upgrading "helped with" to "led". They must be able to defend every line in an interview.
- Hidden or white keyword text and pasting the posting into the CV.
- Layouts with text in images, headers or columns that parsing systems may misread.
- Adding photo, age or marital status without checking local custom.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Each claim traces to something the user supplied or confirmed, essential requirements are shown as evidenced or as gaps, and the posting's instructions are met.
