# Name Change Paper Trail

## When to use
A person's name is changing and records need to follow without locking them out.

## Steps
1. Confirm the country and which document legally proves the change, and whether certified copies or translations are needed.
2. List booked travel, pending applications, exams, property purchases and visas. These may require the ticket or application to match the current ID, so time the change around them.
3. Read official pages to find which record must be updated first, since some agencies check against another's database.
4. Order the chain: foundational government records, then photo ID and passport, then payroll and tax, banks, insurance, health, then everything else.
5. For each, note proof required, original or copy, how long the original is kept, fee and processing time. Never send the only original to two places at once.
6. Include professional licences, diplomas, vehicle, property title, will, beneficiaries and travel loyalty accounts.
7. Update email display name and logins last enough that recovery for other accounts still works.
8. Track each row until the new name is visibly confirmed.

## Watch out for
- A passport update during an upcoming trip leaving no travel document.
- Immigration records with their own rules and deadlines.
- Closing an old email used for verification.
- Assuming one agency informs the others.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
The update order respects dependencies and booked events, and each record is confirmed or dated for follow-up.
