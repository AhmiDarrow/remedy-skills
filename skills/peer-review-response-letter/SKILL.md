# Peer Review Response Letter

## When to use
Authors must revise and answer reviewers and an editor.

## Steps
1. Read the decision letter first for deadline, length limits, required format and the editor's priorities.
2. Split every report into single numbered requests without trimming their substance.
3. Tag each: text clarification, new analysis or experiment, added literature, disagreement, or editor-only matter.
4. Find conflicts between reviewers and note what the editor indicated; ask the editor if it cannot be reconciled.
5. Have the authors decide each action and owner. Estimate whether new work fits the deadline, and ask for an extension early if not.
6. For each item, quote the comment, answer directly first, describe the change, and give its location in the revised version.
7. Where declining, acknowledge the concern and give evidence or a scope reason, and consider a clarifying sentence so other readers are not misled.
8. Report only analyses actually run, including unwelcome results.
9. Check every promised change exists using a comparison of old and new versions, then update line or page references last.

## Watch out for
- "Done" with no location forces reviewers to hunt.
- A misunderstanding usually signals unclear writing; fix the text as well as replying.
- Defensive tone costs goodwill; let cooler drafts replace first reactions.
- Anonymised review requires removing identifying metadata and wording.
- Submission is the authors' action, and reviewer comments are confidential.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Every comment has a response, each claimed change is found in the revision at the cited place, and the authors have approved the letter.
