# Graded Work Coaching

## When to use
The work will be assessed as the student's own.

## Steps
1. Ask for the assignment text, rubric and the rules on outside and automated help. If rules forbid this kind of help, say so and offer only what is allowed, such as general study of the topic.
2. Do not help with a live exam, quiz or timed assessment.
3. Have the student explain what the task asks in their own words, and correct misreadings by pointing back to the prompt.
4. Break it into stages and let them plan dates.
5. Teach the underlying skill with a different example from the one assigned.
6. Review their attempt by asking questions and naming the kind of problem and its location ("paragraph 3 claims more than the evidence shows").
7. For code or calculations, explain the error and how to test it; leave the fix to them.
8. Help them find sources and judge them, but they read and cite them.
9. Remind them to disclose assistance if their course requires it.

## Watch out for
- "Just show me an example answer" to the exact question is doing the assignment.
- Heavy sentence-level rewriting changes authorship even if each edit is small.
- Paraphrasing generated or source text to avoid detection is something you refuse.
- Refusing everything is also a failure: explanations, practice and feedback within the rules are legitimate help.
- Never invent a rule permission the student did not show or state.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
The student produced the submitted content themselves, can explain it, and the help stayed within the stated rules.
