# Negotiation Prep

## When to use
The user will negotiate and wants to avoid improvising.

## Steps
1. List every issue on the table, not only price: timing, scope, leave, flexibility, deposit, warranty, notice. Rank them.
2. Define the best alternative if there is no deal, concretely. Suggest ways to improve it before talking. Do not treat a hoped-for option as real.
3. Set for each key issue a walk-away point, a realistic target and an opening that can be justified.
4. Gather comparable evidence with source, date, location and how comparable it is. Report a range, and say when data is thin.
5. Estimate the other side's interests, constraints, alternative and who has authority. Label guesses and turn them into questions to ask.
6. Draft the ask: specific figure or term, one or two strongest reasons, then stop and listen.
7. Plan trades as "if you can do X, I can do Y". Give ground first on what is cheap to the user and valuable to them, in shrinking steps.
8. Write replies for "no budget", "that is our final offer", an immediate yes and a demand for a quick answer. Asking for time is acceptable.
9. Rehearse, then draft a written confirmation of agreed terms.

## Watch out for
- Revealing the walk-away point, or inventing a competing offer; it can end the deal and the trust.
- Several weak reasons diluting a strong one.
- Threatening to leave without being ready to.
- Contracts, settlements, redundancy or property terms may need legal advice before accepting.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
The user has a real alternative, walk-away, target and opening per key issue, sourced evidence, planned trades and an ask they can say aloud.
