# Deposit Return Claim

## When to use
Deductions have been proposed, or the deposit is overdue after move-out.

## Steps
1. Gather the lease, move-in inventory and photos, move-out photos, key return proof, payment records and all messages. Note the move-out date.
2. Find the rules for this place on an official or tenant advice site: where the deposit must be held, return deadline, dispute scheme and its time limit. Quote the source and date. If unsure which rules apply, say so and refer to an advice service.
3. Ask for an itemised list with an invoice or quote per deduction if not given.
4. Make a table with one row per deduction: amount, claim, move-in evidence, move-out evidence, position (accept, part accept, reject) and reason.
5. For each row consider fair wear and tear, item age, whether the charge is for repair or full new replacement, and whether the fault existed at move-in. These are arguments to raise, not guaranteed outcomes.
6. Draft a calm reply stating the amount accepted, amount disputed, evidence attached and a date for response. The person approves and sends.
7. If unresolved, prepare the evidence bundle for the dispute scheme or small claims route, indexed and named by row, and put its deadline in the file.

## Watch out for
- Accepting a partial refund with wording that settles the whole claim.
- Missing the scheme's time limit while negotiating informally.
- Long emotional narratives that bury the evidence.
- Sending the only copy of anything.

## Done when
Each deduction has a position with linked evidence, and either money is agreed or a bundle is ready with its filing deadline.
