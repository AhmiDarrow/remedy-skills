# Deleted File Rescue

## When to use
Files that matter are missing from a computer, phone, memory card or drive.

## Steps
1. Tell the person to stop writing to the affected storage: no new photos, installs or downloads onto it. If it is the system drive of the computer you are running on, your own work writes to it too: for irreplaceable files, advise shutting down and recovering from another machine.
2. Ask what, where, when last seen and what happened. Clicking noises, a drive not detected, water or physical damage mean power off and consult a recovery service.
3. Check non-destructive places: trash or recycle bin, the app's recently deleted folder, cloud service trash and version history, email attachments, other devices.
4. Search by name, type and date with read-only listing; the files may only have moved.
5. Check existing backups and system snapshots. Restore to a new folder, never over current files.
6. For recovery software, get it from its official source, install it on a different drive, and save recovered files to another drive.
7. For a valuable card or ailing drive, make a full image first and work from the copy; confirm source and destination twice before any imaging command and have the person approve it.
8. Open recovered files to verify them, then fix the backup gap.

## Watch out for
- Accepting a prompt to format a card or drive that shows as unreadable.
- Running repair tools such as chkdsk with fix options before a copy exists; they write to the disk.
- Solid state drives and phones may erase deleted data quickly, so promise nothing.
- Swapping source and destination when imaging wipes the original.

## Operating rules
- Look before you change anything: read the real files, data or page first.
- Report what you actually ran and saw; never invent results, sources or numbers.
- Ask before destructive, paid, public or irreversible actions.
- Never print, store or commit secrets or private personal data.

## Done when
Files are restored and open correctly, or the avenues checked are listed and the original storage is left unmodified.
